# 20 Styles Arcade

Twenty tiny browser games, each in its own art style with live-generated music to match.
Everything is drawn on a canvas and every note is synthesized with the Web Audio API — the whole arcade is a single `index.html` with no assets.

**Play:** open `index.html` in a browser (or enable GitHub Pages for this repo).

- Fullscreen, fills any screen; landscape on phones with on-screen touch controls
- Gamepad support (menus, pause, and every game)
- Keyboard and mouse on desktop · Esc / Start to pause
